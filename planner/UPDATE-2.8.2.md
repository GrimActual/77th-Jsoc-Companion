# 77th JSOC ORBAT Planner v2.8.2 — Sarge field guide

Click **? Ask Sarge** in the bottom-right corner. Search for a feature (CSV, HVT, scale, backup), choose a topic, and use **Show me where** when available to open its panel. Previous/Next browse the filtered results; clearing the search restores all topics. Escape closes help.

- Expanded from 14 to 23 topics, covering AO injection/filtering, side missions, scaling preferences, mission clock/event log, CSV/Excel exchange, export overlap spacing, customizable shortcuts, offline terrain and briefing controls.
- Added searchable help, including translated terms and accent-insensitive matching.
- Added navigation buttons for relevant tabs, collapsed sections, Settings categories and presentation export. They do not import files, place objects or change the plan.
- New help and search controls translated into French and German. Existing layout, Sarge illustration and planner functionality retained.
- Reiterates current limitations: manually placed objectives, independent mission clock, planner-format CSV and deferred geographic/native Excel formats.

Extract the full Windows ZIP into a new folder and run the EXE. All v2.8.1 features remain included; see UPDATE-2.8.1.md for their instructions. Previous release folders are retained.
