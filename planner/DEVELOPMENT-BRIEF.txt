Starting Saturday, 10 October 2026
Our goal is to build a professional, reliable Arma Reforger mission-planning application, eventually capable of evolving into the Tactical Operations Center (TOC) & ORBAT Suite.
🟢 PART 1 — TOMORROW'S DEVELOPMENT PRIORITIES
These are our immediate priorities, generally organised from simplest to more difficult.
⚙️ 1. Settings & Personalisation
A dedicated settings window accessible through a gear icon in the top-right corner.
Features:
- Light and dark themes.
- Interface scaling.
- Language selection and multilingual support.
- Regional date and time formats.
- Metric and imperial measurements.
- Accessibility settings.
- Adjustable text sizes.
- High-contrast mode.
- Reduced animations.
- Grid visibility.
- Snap-to-grid.
- Default canvas zoom.
- Default export format and quality.
- Keyboard shortcut preferences.
- Restore default settings.
💾 2. Saving & Data Protection
Maintain our existing autosave functionality while improving user control.
Features:
- Clear save status: Saved, Unsaved, Saving and Failed.
- Manual Save Backup button.
- Timestamped JSON backup files.
- Automatic validation when creating a manual backup.
- Confirm backup files contain valid project information.
- Prevent accidental overwriting of previous backups.
No automatic backup scheduler or complicated automatic recovery system.
🖱️ 3. Canvas Editing & Keyboard Shortcuts
Make the ORBAT canvas faster and easier to work with.
Features:
- Click-and-drag selection box.
- Ctrl + click multi-selection.
- Move multiple selected units together.
- Delete key activates existing Delete function.
- Ctrl + A — Select all.
- Ctrl + D — Duplicate.
- Ctrl + C / V — Copy and paste.
- Ctrl + Z / Y — Undo and redo.
- Escape — Deselect/cancel.
- Space + drag — Pan canvas.
- Align objects horizontally and vertically.
- Distribute objects evenly.
- Lock objects to prevent accidental changes.
- Fit entire ORBAT to screen.
- Optional selection behaviour for partially enclosed objects.
Keyboard shortcuts must not interfere with typing in text fields.
🖥️ 4. Presentation & Export Improvements
We're keeping our existing image/document exports and improving their capabilities.
Features:
- SVG export.
- Full-canvas export.
- Current-view export.
- Selected-object export.
- Export preview.
- Full-screen briefing mode.
- Hide editing sidebars.
- Expand the map for Discord screen sharing.
- Include or exclude grid and map backgrounds.
- Custom unit patches and logos.
- Community branding.
- Operation titles and dates.
- Adjustable image watermarks.
- Custom fictional classification stamps.

🔒 Our non-negotiable development principles
Throughout development, we'll stick to these rules:
✅ Never unnecessarily rewrite working features.
✅ Protect existing saved ORBAT projects.
✅ Keep backups manual and user-controlled.
✅ Keep the application fully functional offline.
✅ Make advanced systems optional.
✅ Test changes individually before moving forward.
✅ Prioritise performance, reliability and usability over unnecessary complexity.
✅ Maintain compatibility with older project files wherever possible.
🫡 The bigger picture
We're effectively planning three stages of the application's evolution:
Stage 1 — Professional ORBAT Editor
Fast, reliable, customisable and easy to use.
Stage 2 — Complete MilSim Mission Planner
Map intelligence, OPORD generation, logistics, briefing tools and Game Master controls.
Stage 3 — Reforger Tactical Operations Center (TOC)
Optional game integration, collaborative planning, community mod support and advanced simulation.
