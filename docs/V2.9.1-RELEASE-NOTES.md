# COMMAND — ORBAT / Mission Planner v2.9.1 Preview 1

Dedicated-server integration is experimental, pending Enfusion compilation and a real dedicated-server session. This preview is not a stable replacement for the proven RC2 player-hosted build.

- Full map hides menus; Full screen/F11 uses the display; Show menus/Escape restores the layout without losing unsaved fields.
- Saved local/player-hosted and dedicated profiles with edit/delete/select/connect controls; no stored secrets or startup auto-connect.
- Existing free tunnel and manual relay/local receiver remain available.
- Dedicated v2 relay sessions restrict writes to one entity ID with ordered revisions and duplicate handling.
- Five bounded reconnect attempts, cancellation, authentication/expiry explanations, seven-second stale-marker watchdog.
- Session-only safety diagnostics, request/response counters and last valid position timestamp.
- Opt-in server addon candidate reads a private profile JSON and sends only one administrator-named scenario entity. No local player controller required for this new sender.
- New Sarge guides in English, French and German. Server-specific instructions identify exactly which config fields receive the address/code.
- No new dependencies; no game-process access or commands into the game. Existing map alignment, offline editing, saves, exports and undo remain separate.

See DEDICATED-SERVER.md for setup and restrictions, V2.9.1-AUDIT.md for the pre-change audit, and V2.9.1-TEST-REPORT.md for observed results and unverified gates.
